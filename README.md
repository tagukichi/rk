# 株式会社オフィスＲＫ コーポレートサイト（静的版・1ページ構成）

ヒアリングシート（2026/7/17受領）をもとに制作した HTML/CSS/JS の静的サイト。
**1ページ完結（ワンページ）構成。** デザイン確定後に WordPress テーマ化する。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 全セクション（ヒーロー／私たちについて／事業内容／実績事例／会社概要／お問い合わせCTA） |
| `assets/css/style.css` | 共通スタイル |
| `assets/js/main.js` | ヘッダー・ハンバーガー・スクロールリビール |

## 仕様上の決定事項

- **1ページ構成**：ナビはページ内アンカーリンク
- **お問い合わせフォームは作らない**：「お問い合わせはこちら」ボタンで外部リンクにする
  - 現在は仮で `mailto:office-rk.est@ymail.ne.jp`。外部フォームURL確定後に差し替え
- **WPの投稿・カスタム投稿タイプは使わない**（お知らせ機能なし）
  - WP化の際は固定フロントページ1枚のシンプルなテーマにする

## デザイン方針

- ヒアリング「シンプル＋先進的」に基づく設計
- 白基調＋濃紺（#0f1c2e）＋アクセントブルー（#0e6fff）
- フォント: Noto Sans JP ＋ Inter（英語アクセント）
- ヒーロー背景にビル群イラスト画像（`assets/img/hero-skyline.png`）を全面配置。左側に淡いベールを重ねてテキストの可読性を確保

## プレビュー

```bash
python -m http.server 5507 --directory .
```

## 差し替え待ちの素材（プレースホルダー）

- ロゴ → 現在はテキストロゴ「RK」。ロゴデータ受領後に差し替え
- 実績事例 → サンプル文＋「No Image」。実データ確定後に差し替え
- お問い合わせ外部リンクURL → 確定後に `mailto:` から差し替え

## WordPress化の際のメモ

- `index.php`（または `front-page.php`）＋ `header.php` / `footer.php` のみの最小テーマ
- 投稿・CPT・アーカイブ系テンプレートは不要
